# Clínica de Psicología Financiera — repo de trabajo del manuscrito

Este repositorio existe únicamente para que la rutina automática diaria (cloud) pueda leer y escribir el avance del libro *Clínica de Psicología Financiera*, de Luis Raúl "Billy" Irigoyen Carrillo, fundador de Psicología Financiera®.

## Archivos

- `manuscrito.md` — el manuscrito de trabajo. Aquí es donde se escribe cada sección nueva. El .docx original del autor (`Libro Psicología Financiera.docx`) vive fuera de este repo, en su computadora, y no debe editarse desde aquí.
- `estado_avance_libro.md` — controla en qué sección está el avance y si ya fue aprobada por el autor. **Leer este archivo primero en cada corrida.**
- `contexto_identidad.md` — tesis, propósito y modelo AFC del libro.
- `contexto_estructura.md` — índice completo y estado real de cada capítulo.
- `contexto_estilo.md` — reglas de estilo, criterio de fuentes y las 15 instrucciones para cualquier IA que continúe el proyecto.

## Regla de oro

No avanzar a la siguiente sección sin que `estado_avance_libro.md` indique que la sección actual fue `aprobado` por el autor. Ver el detalle completo de la lógica en ese archivo.
